Filtres disponibles

Combinez les filtres avec AND, OR et NOT. Les valeurs contenant des espaces doivent etre entre guillemets.

name:

Recherche dans le nom de la carte.

name:Lightning name:"Llanowar Elves" name:dragon

type:

Recherche dans la ligne de type.

type:Creature type:Artifact type:"Legendary Creature"

text:

Recherche dans le texte oracle.

text:draw text:"enters the battlefield" text:destroy

text_regex:

Recherche avancee par regex insensible a la casse dans le texte oracle.

text_regex:"damage .* opponent" text_regex:"deals? .* damage" text_regex:"creature an opponent controls"

Pour un OU dans la regex, groupez toujours les options : text_regex:"damage to (target|each) opponent". Sans parentheses, target|each veut dire "target" ou "each" n'importe ou.

NOT

Exclut un filtre. Utile pour retirer les faux positifs.

text_regex:"deals?.*damage" AND NOT text_regex:"combat damage" type:Creature AND NOT keyword:Flying

keyword:

Recherche dans les mots-cles importes.

keyword:Flying keyword:Trample keyword:Vigilance

set:

Filtre les cartes qui ont une impression dans cette extension, par code ou par nom.

set:mrd set:Mirrodin set:"Modern Horizons"

query: / query_id:

Reutilise une requete sauvegardee visible, puis combine-la avec AND, OR ou NOT.

query:"Removal" query:"Fixing" OR query:"Creatures volantes" query_id:12 AND set:mrd

color:

Carte contenant cette couleur parmi ses couleurs.

color:W color:U color:R

identity:

Carte contenant cette couleur dans son identite couleur.

identity:G identity:B identity:U

mv

Compare la mana value. Operateurs disponibles : =, <, <=, >, >=.

mv=2 mv<=3 mv>=6

power

Compare la force numerique.

power=2 power>=4 power<3

toughness

Compare l'endurance numerique.

toughness=1 toughness>=4 toughness<=2

tag:

Disponible seulement dans les cubes, pas dans la recherche globale de cartes.

tag:removal tag:fixing tag:ramp

Edition / extension

Disponible avec set:. Le code d'extension est le plus fiable, par exemple set:mrd.
